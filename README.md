# The Dark Forest Theory: simulation core (M1 generator, M2 world store and mining, M3 asteroid loop, M4a sandbox, M4b loose bodies)

The native game is in `game/` (Bevy). New session? Start with HANDOFF.md, then ROADMAP.md.

Builds any body from a data file and a seed. Nothing about a body is stored:
`material(x, y)` answers for any 1 m cell, identically on every machine.

## Run it (Windows)

- `run-planetgen.bat`: builds both bodies, writes previews and reports to `out\`
- `run-tests.bat`: runs all tests (generator and world store)
- `run-asteroidloop.bat`: plays five copies of tutorial asteroid 1 to launch with the scripted idle player and writes the run report and growth data (CSV) to `out\`
- `cargo run --release --bin tutorials`: compares ways of pacing the second tutorial asteroid
- `run-sandboxdemo.bat`: opens a corridor between a magma pocket and a water pocket and a cavity under loose rubble, and a moat around a block of rock so it breaks free and falls, runs the sandbox for two minutes and writes frames to `out\sandbox\`
- `run-refsheet.bat`: rebuilds the reference sheets in `reference\` (pictures and a spec sheet per body); add `--glamour 0.5` in the file to see the glamour pass instead
- `run-stress.bat`: pushes bodies and swarms past their usual sizes and reports the cost (see `src\bin\stress.rs` for the settings)
- `run-abundance.bat`: measures how much of every element each body holds (whole body and outer 500 m) and writes `data\reference\abundance.csv`
- `run-game.bat`, `continue-game.bat`, `test-*.bat`: the game, the last save, and the game test setups
- `run-minedemo.bat`: digs tunnels, strip-mines regions and sinks a shaft to the Heart, then saves, reloads, checks the books and renders the result to `out\`

## Layout

- `data/materials.toml`: every material, with density (kg per m3 = kg per cell), hardness, colour, processing multiplier, element composition, phase changes and heat; then the reaction table and the sandbox's physics constants
- `data/elements.toml`: the 75 elements (atomic data, oxides, game value)
- `data/materials-catalogue.toml`: generated by `tools/catalogue.py` (edit the script): rocks, ores, gems, ices, with compositions worked out from mineral formulas and each rock's two trace elements
- `data/geology.toml`: which ore forms where (veins zoned around plutons, skarn, cumulates, accessory pods) and `[geology.scarcity]`, how much of each ore forms (tuned by `tools/tune_scarcity.py`)
- `data/specialties.toml`: planet specialties rolled from each body's seed (rich veins, traces through a rock, trade-off districts, jackpots, asteroid caches) and the roll odds
- `data/reference/crust-ppm.toml`, `abundance*.csv`, `specialties.csv`, `specialty-odds.csv`: Earth's crust and what the bodies measure against it
- `data/economy.toml`: every economy number (costs, rates, upgrades, launch); the drone part recipes at its end are generated by `tools/recipes.py` (rarest element first, rising markup)
- `data/bodies/*.toml`: one file per body (layers, caves, blobs, veins, sprinkles, pipes, craters)
- `src/planet.rs`: the generator, `material(x, y)`
- `src/totals.rs`: quadtree nodes, exact counts and fast estimates of mass per material and element
- `src/world.rs`: the world store, a sparse quadtree of changes over the generator; mining by cell or by whole region; regions collapse when emptied
- `src/ledger.rs`: the books; every kilogram mined, every estimate correction, credited Mass and processing bonus
- `src/save.rs`: compressed saves with a body fingerprint
- `src/specialty.rs`: rolls and applies a body's specialties; `bias` lets the meta tree steer the roll
- `src/recipes.rs`: the element stockpile (raw and refined) and building from part recipes
- `src/bin/abundance.rs`: element abundance per body, specialty odds
- `src/swarm.rs`: the seed swarm, drones (individuals plus a packet beyond the cap), Mass and Energy, building, upgrades, launch
- `src/sandbox.rs`: falling sand, heat and reactions on the cells near activity; mass is always kept
- `src/bodies.rs`: loose rigid bodies (Rapier, deterministic mode): rock cut free by digging falls, tumbles and sets down again; wrecked drones become scrap
- `data/glamour.toml`: the glamour pass's rules (interior eye candy over the realistic model)
- `data/reference/fingerprints.toml`: the locked fingerprint of every body; `tests/reference.rs` fails if generation changes one (re-save with `BLESS=1`)
- `reference/`: a spec sheet per body (disc, surface, dive to the centre, close-up, other seeds, layers, depth profile, cost)
- `src/glamour.rs`: the glamour pass: provinces, banding, lumps, seams, geodes, crystal caverns, core rings; set per body with `glamour = 0..1`
- `src/palette.rs`: colour schemes: above glamour 0 each body draws its materials in a colour harmony (analogous, complementary, split-complementary, triadic or square) around a base hue from its seed; pin them with `[palette] scheme = "triadic"` and `hue = 210` in a body file. `cargo run --release --bin palettesheet -- <body> out.png` shows one body in many palettes
- `src/texture.rs`: block textures, bevels and the backdrop behind eaten ground (viewer only; no effect on the simulation)
- `src/reference.rs`: fingerprints and depth profiles for the reference sheets
- `src/render.rs`: PNG previews (underground draws darker; hot liquids and the Heart glow)
- `src/bin/planetgen.rs`: builds bodies and reports their content
- `src/bin/minedemo.rs`: the M2 mining demo
- `src/bin/asteroidloop.rs`: the M3 asteroid loop runner
- `src/bin/sandboxdemo.rs`: the sandbox demo
- `src/bin/tutorials.rs`: plays tutorial asteroid 1, buys prestige perks with its Seed Mass, then plays the second tutorial several ways
- `tests/generator.rs`: determinism, Heart placement, parts-sum-to-whole, estimate accuracy
- `tests/swarm.rs`: same run every time and at any thread count, balanced books, the swarm never stops building, the asteroid reaches launch
- `tests/sandbox.rs`: cave-ins keep mass and balance the books, lava crusts over and water quenches it, same result every run
- `tests/bodies.rs`: a block cut free falls and lands with every kilogram on the books at every tick, the same fall every run, wrecked drones leave scrap
- `tests/world.rs`: mining, balanced books, collapse, save round-trips, same world at any thread count

Add a body by copying a file in `data/bodies/` and changing its numbers; no code needed.
